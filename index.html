자주 묻는 질문

언제 멈추나요?
다른 탭으로 이동하거나 창을 최소화하면 절전 방지가 일시 중단됩니다. 직접 중지했거나 타이머가 끝난 경우를 제외하면, 창이 다시 보일 때 절전 방지를 다시 요청합니다. macOS에서는 다른 데스크톱(스페이스)에 있거나 다른 창에 완전히 가려져도 중단될 수 있습니다. 다른 창에서 작업할 때는 Wakeup을 작은 창으로 열어 화면에 보이게 두세요.
노트북 덮개를 닫거나, 화면만 끄고 컴퓨터를 깨워 둘 수 있나요?
아니요. Wakeup은 화면이 꺼지는 것만 막을 수 있습니다. 덮개를 닫거나 운영체제가 절전 모드 또는 저전력 모드를 적용하면 이 기능이 제한될 수 있습니다. 화면을 끈 채 다운로드나 작업을 계속하려면 운영체제의 전원 설정을 사용하세요.
배터리가 더 빨리 닳나요?
화면을 켜 두면 꺼져 있을 때보다 전력을 더 씁니다. Wakeup은 표준 Screen Wake Lock 기능을 사용합니다.
설치해야 하나요? 어떤 브라우저에서 되나요?
설치 없이 브라우저에서 열면 됩니다. 온라인에서 앱 파일을 불러와 브라우저에 저장한 뒤에는 오프라인에서도 열 수 있습니다. 표준 Screen Wake Lock 기능을 지원하는 데스크톱 브라우저가 필요합니다.
사용 기록이나 개인정보를 수집하나요?
아니요. 쿠키, 설정·이용 기록 저장, 분석 코드가 없습니다. 오프라인 실행에 필요한 앱 파일만 브라우저에 캐시됩니다.
