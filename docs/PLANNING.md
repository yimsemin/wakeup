# Wakeup 기획서

## 1. 목적

Wakeup은 Windows와 macOS의 데스크톱 브라우저에서 화면이 꺼지지 않게 하는 단일 페이지 웹앱이다. 개발 가이드는 [AGENTS.md](../AGENTS.md)를 따른다.

## 2. 제품 원칙

- 현재 절전 방지 상태와 사용자가 취할 수 있는 동작을 먼저 보여 준다.
- 서버 기능과 사용자 계정 없이 동작한다.

## 3. 기능 범위

### 3.1 절전 방지

- Wakeup을 열면 화면이 보일 때 Screen Wake Lock을 자동으로 요청한다. 작은 창은 원래 창에서 받은 설정에 따라 시작한다.
- 페이지가 보이는 상태에서 자동 요청이 거부되면 시작 버튼을 안내한다. 사용자 조작으로 요청했다가 거부된 경우에는 오류와 재시도 버튼을 표시한다. 거부 사유가 `NotAllowedError`이면 저전력 모드, 배터리 절약 모드, 전원 정책을 가능한 원인으로 안내한다.
- 브라우저나 운영체제가 잠금을 해제하면 상태를 갱신한다. 페이지가 보이면 즉시 재요청하되, 잠금을 얻고 2초 안에 풀리는 일이 세 번 연속 발생하면 즉시 재요청하는 흐름을 멈추고 시작 버튼을 안내한다.
- 페이지가 다시 보이면 절전 방지를 직접 중지했거나 타이머가 끝난 경우를 제외하고 잠금을 다시 요청한다.
- 절전 방지를 요청 중이거나 진행 중이면 중지할 수 있다. 절전 방지가 꺼져 있거나 타이머가 끝나면 다시 시작할 수 있고, 일시 중단이나 오류 상태에서는 다시 시도할 수 있다.

### 3.2 타이머

- 기본값은 `제한 없음`이다.
- `제한 없음`, 15분, 30분, 1시간, 2시간은 버튼으로 바로 선택한다. `직접 입력`은 시간 0~999, 분 0~59의 정수를 입력하고 `적용`을 누른다. 빈 값, 범위를 벗어난 값, 정수가 아닌 값 또는 합계 0은 현재 화면 언어로 안내한다.
- 절전 방지 중에 시간을 바꾸면 선택한 시간으로 타이머가 다시 시작한다. 일시 중단 중에 시간을 바꾸면 절전 방지가 재개될 때부터 흐른다. 타이머 종료 후 시간을 바꾸면 절전 방지가 꺼진 상태로 돌아가며, 설정한 시간은 다음 시작에 적용된다.
- 타이머가 끝나면 잠금을 해제하고 종료 상태와 남은 시간 0을 표시한다. 해당 창에서 오디오가 준비됐고 알림음 크기가 0보다 크면 짧은 종료 알림음을 한 번 재생한다.
- 시간 제한을 설정하면 종료 알림음 크기 조절과 미리 듣기를 제공한다. 기본값은 40%이며 새로 열면 기본값으로 돌아간다. 해당 창에서 오디오를 준비하려면 화면을 누르거나 `Esc` 이외의 키를 눌러야 한다. 크기가 0이면 미리 듣기를 비활성화하고, 오디오를 지원하지 않으면 크기 조절도 비활성화한다. 각각의 경우 알림음 영역에 이유를 표시한다.

### 3.3 시간 표시

- `절전 방지 시간`과 `남은 시간`은 잠금이 활성화된 구간의 실제 경과 시간을 기준으로 `시:분:초`를 표시한다. 잠금이 풀리면 두 값의 진행이 멈춘다.
- 절전 방지가 꺼져 있으면 다음 시작에 적용할 시간을 `다음 타이머`로 표시한다. 시간 제한을 설정하고 절전 방지가 진행 중이면 예상 종료 시각을 시·분 단위로 함께 표시한다.
- 페이지가 보이는 동안 잠금이 예기치 않게 해제되면 `중단 횟수`에 포함한다. 한 번 이상 중단된 뒤 절전 방지가 다시 진행 중이면 상태 설명에 가능한 원인을 안내한다.
- 새 절전 방지 세션을 시작하거나 페이지를 다시 열면 절전 방지 시간과 중단 횟수를 초기화한다. 작은 창은 [3.8절](#38-작은-창)에 따라 원래 창의 절전 방지 시간을 이어받는다.

### 3.4 언어

- URL의 `lang=ko` 또는 `lang=en`을 우선 적용한다. 유효한 값이 없으면 브라우저 언어가 영어일 때 영어로, 그 밖에는 한국어로 표시한다.
- 언어 전환 시 화면과 URL의 `lang` 값을 새로고침 없이 갱신한다.

### 3.5 오프라인 및 설치

- 온라인 방문에서 Service Worker가 앱 파일을 캐시한 뒤에는 오프라인에서도 열 수 있다. Service Worker를 설치할 때 앱 파일을 서버에서 다시 받고, 활성화할 때 이전 Wakeup 캐시를 정리한다.
- 설치를 지원하는 브라우저에서는 Web App Manifest를 통해 독립 창에서 실행하는 앱으로 설치할 수 있다.

### 3.6 검색 기본 정보

- 서비스명은 `Wakeup`, 한 줄 설명은 한국어 `브라우저에서 화면이 잠들지 않게.`, 영어 `Keep your screen awake in the browser.`를 사용한다.
- 설명적인 문서 제목과 메타 설명, 단일 `h1`, canonical URL을 제공한다. canonical URL은 기본 배포 주소를 사용하고, `lang` 매개변수가 있으면 현재 표시 언어의 주소로 갱신한다.
- Open Graph와 Twitter Card 메타를 제공한다. `og:image`는 `icons/icon-512.png`의 절대 URL을 사용한다.
- `hreflang` 대체 링크는 한국어에 `?lang=ko`, 영어에 `?lang=en`, `x-default`에 기본 배포 주소를 연결한다.
- JSON-LD로 `WebApplication`의 무료 `Offer`, `UtilityApplication` 분류, 지원 운영체제와 `FAQPage`를 제공한다. `FAQPage`의 질문과 답변은 기본 한국어 화면과 일치시킨다.
- 루트의 `robots.txt`는 전체 허용과 사이트맵 경로를, `sitemap.xml`은 기본 배포 주소와 `ko`·`en`·`x-default` 대체 링크를 제공한다. 두 파일은 Service Worker 앱 셸에서 제외한다.

### 3.7 테마

- 라이트와 다크 테마를 제공한다. 상단 버튼으로 테마를 선택하기 전에는 시스템 설정을 따르며, 페이지를 다시 열면 시스템 설정으로 돌아간다. 테마 버튼의 `aria-pressed`는 다크 모드 여부를 나타낸다.

### 3.8 작은 창

- 다른 작업을 할 때 Wakeup을 별도 창으로 열어 화면에 띄워 둘 수 있다. 작은 창과 설치 앱에서는 이 버튼을 숨기고, 팝업이 차단되면 허용 방법을 안내한다.
- 열 때는 원래 창에서 작은 창으로, 닫을 때는 작은 창에서 원래 창으로 타이머 설정과 종료 여부, 남은 시간, 절전 방지 시간, 시작·중지 여부, 언어와 선택한 테마를 전달한다.
- 작은 창에서 원래 창의 설정을 받지 못하면 시작 버튼을 안내한다.

### 3.9 전체 화면 시계

- 어두운 배경과 밝기를 낮춘 글자로 현재 시각을 크게 표시한다. 타이머를 설정한 경우 본 화면과 같은 `남은 시간` 또는 `다음 타이머`를 표시한다.
- 브라우저가 전체 화면을 지원하지 않거나 요청을 거부하면 페이지를 덮는 시계 화면을 표시한다. `Esc` 또는 클릭으로 돌아가면 시계 열기 버튼에 포커스가 돌아온다.
- 마우스를 3초간 움직이지 않으면 커서와 복귀 안내를 숨긴다. 절전 방지가 켜져 있으면 화면이 가려질 때 일시 중단된다는 안내를 표시한다.

## 4. 화면 구성

가로 중앙에 놓인 단일 패널에 다음 요소를 위에서 아래 순서로 배치한다.

1. 서비스 이름, 한 줄 설명, 테마 버튼과 한국어/영어 전환 버튼
2. 현재 절전 방지 상태, 간단한 설명, 활성 누적 시간과 필요 시 남은 시간·예상 종료 시각·중단 횟수
3. 시작·중지 또는 재시도 버튼과 그 아래 `Space` 키 안내
4. 타이머 즉시 선택 버튼, 필요 시 직접 입력 영역, 종료 알림음 크기 슬라이더와 미리 듣기 버튼
5. `작은 창으로 열기`와 `전체 화면 시계로 보기` 버튼 및 각각의 설명. 공간이 충분하면 나란히 두고 좁으면 세로로 배치한다.
6. 항상 펼쳐진 `자주 묻는 질문` 섹션. 다섯 문답으로 작동이 멈추는 조건, 운영체제·덮개 제약, 배터리, 설치·브라우저, 개인정보를 안내한다.
7. 프로젝트 저장소(GitHub)로 나가는 링크

## 5. 상태 정의

- `requesting`: 절전 방지를 요청 중인 상태
- `prompt`: 사용자 조작이 필요한 상태. 자동 요청 거부, 반복 해제 또는 작은 창에 설정 응답이 없는 경우에 사용한다.
- `active`: Wake Lock이 실제 활성화된 상태
- `idle`: 절전 방지가 꺼져 있는 상태
- `suspended`: 페이지가 가려졌거나 브라우저 또는 운영체제가 잠금을 해제해 일시 중단된 상태
- `expired`: 설정한 타이머가 종료된 상태
- `unsupported`: 브라우저가 Screen Wake Lock을 지원하지 않는 상태. 시간 표시와 절전 방지·타이머 조작을 숨기고 다른 데스크톱 브라우저에서 열도록 안내한다.
- `error`: 사용자 조작으로 요청했으나 브라우저가 거부한 상태

상태는 색상과 함께 제목과 설명으로 전달하고, 변경 사항은 `aria-live` 영역으로 알린다. 일시 중단, 타이머 종료, 오류 상태는 브라우저 탭 제목에도 표시한다.

## 6. 개인정보

쿠키나 이용 기록을 남기지 않고 분석 도구를 사용하지 않는다. 언어 선택은 URL에 반영하며, 타이머·테마·알림음 설정은 앱을 사용하는 동안에만 유지한다. Service Worker 캐시에는 오프라인 실행에 필요한 앱 파일만 저장한다.

## 7. 브라우저 제약

다른 탭으로 이동하거나 창을 최소화하면 절전 방지가 일시 중단된다. macOS에서 다른 데스크톱(스페이스)으로 이동하거나 창이 완전히 가려져도 일시 중단될 수 있다. Wakeup은 운영체제 절전이나 닫힌 노트북 덮개를 제어할 수 없다. 화면을 끈 채 작업을 계속하려면 운영체제 전원 설정을 사용한다.

## 8. 접근성 및 디자인 기준

- 본문과 조작 요소의 글자 크기는 14pt 이상으로 한다.
- 섹션 의미는 반복적인 상자와 구분선보다 타이포 위계와 여백으로 전달
- 충분한 명암비와 명확한 키보드 포커스 제공
- 모든 입력 요소에 연결된 레이블 제공
- 의미 없는 애니메이션과 지속적인 움직임 사용 안 함
- 절전 방지의 기본 버튼은 `Space` 키로도 실행할 수 있다. 입력란·버튼·링크·편집 영역에 포커스가 있으면 해당 요소의 키 동작을 유지한다.
- 한글 본문은 어절 단위로 줄바꿈한다.
- 좁은 창에서도 내용과 조작 요소를 사용할 수 있게 배치한다.
- 타이머·알림음·직접 입력 영역이 나타나고 사라져도 위쪽 요소(특히 시작·중지 버튼)의 위치가 흔들리지 않도록 카드를 세로 가운데가 아닌 위로 정렬
